# 🎓 FindIt Campus
### Lost something on campus? Let's help you find it.

FindIt Campus is a digital Lost & Found platform designed to connect people who lose belongings with those who find them within a college campus.

Instead of relying on word-of-mouth announcements or scattered messages, FindIt Campus brings lost and found information into one accessible platform.

---

## 💡 The Problem

Students frequently lose personal belongings such as ID cards, notebooks, wallets, keys, and electronic accessories around campus.

Finding these items again can be difficult because information is often scattered across classrooms, groups, and informal communication channels.

## 💻 Our Solution

FindIt Campus creates a centralized space where campus members can:

- Report items they have lost.
- Share details about items they have found.
- Explore reported belongings.
- Search for items using relevant information.

Our goal is to make the recovery process more convenient and organized.

## ✨ Key Features

| Feature | Description |
|---|---|
| Lost Item Reporting | Submit details of missing belongings. |
| Found Item Reporting | Share information about recovered items. |
| Item Browsing | Explore available listings. |
| Search | Find relevant listings more easily. |
| User Interface | Access the platform through a simple interface. |

## 🚀 Getting Started

Follow these steps to run FindIt Campus locally.

### 1. Clone the repository

```bash
git clone https://github.com/anweshabehera-arch/findit-campus.git
```

### 2. Navigate to the project directory

```bash
cd findit-campus
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the localhost URL displayed in your terminal to access the application.
